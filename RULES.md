# agentic-forms rules

These rules bind every run of agentic-forms. They also bind agents that use this package.

1. Check before you publish. A refused spec stays refused until you change it.
2. Report failures as failures. Show the issue list. Never call a failed check a success.
3. Keep answers private. Do not write answer content or email addresses to a log.
4. Keep consent real. Never set consent on behalf of a person.
